# Crypto Market Analyser – UiPath Automation

## Project Overview

The **Crypto Market Analyser** is an automation project developed using **UiPath RPA**.
This automation collects cryptocurrency market data and processes it to help users quickly analyze market trends without manually visiting multiple websites.

The project demonstrates the use of **Robotic Process Automation (RPA)** to automate repetitive data collection and analysis tasks.

---

## Features

* Automated retrieval of cryptocurrency market information
* Data extraction from web sources
* Structured data processing
* Automation workflow built using UiPath Studio
* Reduces manual effort and time spent analyzing crypto markets

---

## Technologies Used

* **UiPath Studio**
* **Robotic Process Automation (RPA)**
* **XAML Workflows**
* **Web Automation**
* **Data Scraping**

---



## How the Automation Works

1. Launches the required web page containing cryptocurrency data.
2. Extracts relevant market information such as:

   * Cryptocurrency names
   * Prices
   * Market trends
3. Processes the extracted data.
4. Stores or displays the results for analysis.

---

## How to Run the Project

1. Install **UiPath Studio**.
2. Clone this repository:

```
git clone https://github.com/your-username/crypto-market-analyser.git
```

3. Open the project in **UiPath Studio**.
4. Run the **Main.xaml** workflow.
